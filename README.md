# sales-performance-analysis

## Questions This Project Answers
- How do sales change over time?
- Which product categories generate the most revenue?
- How do sales vary by gender and age group?

## Tools Used
- Python (Pandas, Matplotlib)

## Repository Structure 
- 'data/' - retail sales dataset (CSV)
- 'Retail_Sale_Analysis.ipynb' - full analysis notebook (codes, charts and insights)
- 'README.md' - project overview

## Key Insights 
- Elctronics generates the most total revenue ($156,905), closely followed by Clothing($155,580), with Beauty lowest ($143,515).
- Daily sales are volatile with no long-term upward or downward trend, suggesting demand is driven by day-to-day transaction volume rather than seasonal growth.
- Female customers contribute slightly more total sales ($232,840) than male cusomters ($223,160).
- Younger customers (18 -25) spend the most on average per transaction ($500.30), with average spend declining staedily through older age groups down to $412.36 for ages 56-65.
